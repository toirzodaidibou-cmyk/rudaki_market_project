# RUDAKI MARKET — Дафтари корҳо

Дар ин файл ҳар коре, ки дар лоиҳа иҷро мешавад, бо тартиб сабт карда мешавад.

**Қоидаи асосӣ:** ҳеҷ кор бе иҷозати соҳиби лоиҳа иҷро намешавад.

---

## Нақшаи технологӣ (пешниҳод, ҳанӯз тасдиқ нашудааст)

| Қисм | Технология |
|---|---|
| backend | .NET 9, Clean Architecture |
| Пойгоҳи додаҳо | PostgreSQL |
| Ҷустуҷӯ | Meilisearch / Elasticsearch |
| Кэш | Redis |
| Расмҳо | MinIO / S3 + CDN |
| frontend | Next.js (Node.js) |
| admin | React + Vite |

Ҳадаф: системае, ки **2 000 000 мол**-ро бардошта тавонад.

**№12. Backend + Панели админ: идоракунии категорияҳо**

*База (PostgreSQL 18-и алоҳида):*
- Кластери нав дар `C:\Users\HP\.rudaki-market\pgdata`, порт **5434**, танҳо localhost, UTF-8.
